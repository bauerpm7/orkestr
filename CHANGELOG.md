This project adheres to Semantic Versioning. Releases are created from tags of the form `vMAJOR.MINOR.PATCH`.

## Release Notes

GitHub Releases for this project use automatically generated release notes.
When you push a tag like `v0.1.0`, a release is created and notes are compiled
from merged PRs and commit history.

Guidelines:

- Use clear, conventional commit messages when possible.
- Keep PRs focused; include tests and documentation updates.
