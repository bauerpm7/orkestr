# Security Policy

## Supported Versions

We aim to support the latest main branch. Report issues against `main`.

## Reporting a Vulnerability

If you discover a security vulnerability:

- Please open a private report via email to the maintainers or create a GitHub Security Advisory if available.
- Include steps to reproduce and any affected components (Spec, IR, CLI, targets).
- Do not open public issues for sensitive vulnerabilities.

We will investigate and respond promptly. Thank you for helping keep Orkestr secure.
